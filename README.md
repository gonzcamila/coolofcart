# Camila Gonzalez — Cool-Off Cart
A web app built from scratch in HTML, CSS, and JavaScript for WRIT 40363.
When I'm tempted to buy something online, I add it to the cart, and it stays
locked for 48 hours. After that, I decide whether I still want it, and every
item I skip adds to a running total of money saved.

**Live site:** https://gonzcamila.github.io/coolofcart/
## Built with

- Semantic HTML with a labeled, accessible form
- CSS with design tokens, Flexbox, and Grid
- JavaScript with Date.now() to calculate when each item unlocks
- localStorage to save items and decisions
- GitHub Desktop and GitHub Pages

## Notes

- Items are saved in the browser so they stay on the device where they were
  added
- The app saves the time each item unlocks instead of running a countdown,
  so the time left stays correct even after closing the browser
- I built this with Claude AI as a development partner. My process is documented in
  AI_COLLABORATION_LOG.md.
